# Проект для самообучения студентов.
Данное приложение содержит материалы на различные темы, в которых вы можете разобраться и как итог пройти тест на понимание материала.
Также любой зарегистрированный пользователь может сам создать свою любимую тему, которая поможет уже другим пользователям.
## Установка.
1. Клонируйте репозиторий
```https://github.com/HepoH4uk/Diplom```

2. Создайте папку .env в корне проекта и заполните ее по подобию .env.sample

## Как пользоваться приложением.
1. Запустите приложение

2. Для того что бы более подробно ознакомиться с приложением можно перейти по ссылке:
```http://localhost:8000/swagger/```

3. Необходимо зарегистрировать пользователя
```http://localhost:8000/users/register/```

4. Войти в аккаунт с помощью JWT токена
```http://localhost:8000/users/login/```
6. Далее вы можете создавать уроки и тесты, а также пройти тесты других пользователей
Все необходимы для работы url так же находятся в корне каждого приложения)
